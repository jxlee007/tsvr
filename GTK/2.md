 ### 1\. Import `random`

 ### 2\. Create the deck

 You have 32 cards, represented by numbers `0` through `31`.

```
cards = list(range(32))
```

 Think:


---

 ### 3\. Ask the user for a seed

 Get an integer from the user.


---

 ### 4\. Shuffle the deck

 Use the seed first, then shuffle.

```
random.seed(seed)
random.shuffle(cards)
```

 Now `cards` contains the same random order whenever you use the same seed.

---

 ### 5\. Deal four cards


 ### 7\. Understand how a card number works

 Before continuing, make sure you understand this.

 There are 4 suits × 8 ranks:

```
Suit 0 → 0–7
Suit 1 → 8–15
Suit 2 → 16–23
Suit 3 → 24–31
```

 Therefore:

```
card // 8
```

 gives the suit.

 And:

```
card % 8
```

 gives the rank.

 This is one of the most important ideas in the program.

 ### 13\. Mark removed cards as `None`

```

```

 This is important because the table must always have four positions.
